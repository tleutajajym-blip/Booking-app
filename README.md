# Booking App 📱

## About the Project

Booking App is a mobile application developed using React Native and Expo. The application allows users to register, reset their password, select a city, explore different places, view information about establishments, and make reservations.

The main goal of this project is to create a simple and user-friendly mobile application for finding places and booking visits.

## Features

- **Phone Verification:** Users can enter a confirmation code.
- **Password Reset:** Users can create a new password.
- **User Registration:** Users can enter their name, phone number, and password.
- **City Selection:** Users can select their city.
- **Places List:** Users can explore popular places in Almaty.
- **Place Details:** Users can view the name, address, and rating of an establishment.
- **Booking:** Users can select a convenient visit time.
